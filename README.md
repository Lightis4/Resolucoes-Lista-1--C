# 📘 Resoluções — Lista 01 | Linguagem C

Repositório destinado às resoluções da primeira lista de exercícios de programação em **Linguagem C**, com foco no aprendizado dos fundamentos da programação.

## 📚 Conteúdo

O projeto contém 10 exercícios:

1. Primeiro programa — Hello World
2. Apresentação pessoal
3. Declaração de variáveis
4. Trabalhando com `float` e `double`
5. Cadastro de estudante
6. Soma de dois números
7. Calculadora de média
8. Calculadora de idade
9. Calculadora de salário
10. Sistema de cadastro acadêmico

## 🛠️ Tecnologias utilizadas

- **Linguagem:** C
- **Editor:** Visual Studio Code
- **Compilador:** GCC

## ▶️ Como executar

Compile o arquivo desejado utilizando o GCC:

```bash
gcc questao01.c -o questao01
```

Execute o programa:

```bash
./questao01
```

No Windows (PowerShell), utilize `.\questao01.exe`.

## 🎯 Objetivo

Praticar os conceitos fundamentais da linguagem C, incluindo variáveis, tipos de dados, entrada e saída com `scanf()` e `printf()`, operadores aritméticos e cálculos matemáticos.
